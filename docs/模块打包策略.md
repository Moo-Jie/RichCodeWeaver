# 单体打包与部署

后端只产生一个业务可执行 JAR：

`rich-code-weaver-monolith/target/rich-code-weaver-monolith-2.0.jar`

需要管理后台时，再单独打包：

`rich-code-weaver-server-admin/target/rich-code-weaver-server-admin-2.0.0.jar`

原 `common`、`model`、`client`、`user`、`generator`、`ai`、`file`、`prompt`、`social` 等模块已合并到单体 JAR，不再单独部署。

```bash
./mvnw clean package -DskipTests
```

Higress 与 Nginx 将 `/api/**` 转发到单体 8101 端口，Prometheus 抓取 `/api/actuator/prometheus`。
